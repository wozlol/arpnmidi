ARPnMIDI Next-PCB Pin Plan
===========================

This allocation is intended for the dual-brain RP2354A PCB. It also keeps the
design practical to clone with two Waveshare RP2350-Zero modules.


Main brain
----------

The main brain owns musical processing, the controls, sensors, OLED, presets,
and the future ESP32-C3 wireless-MIDI connection.

  GP0   UART0 TX to ESP32-C3 RX
  GP1   UART0 RX from ESP32-C3 TX
  GP2   I2C1 SDA for VL53L0X distance sensor
  GP3   I2C1 SCL for VL53L0X distance sensor
  GP4   UART1 TX to secondary-brain GP5
  GP5   UART1 RX from secondary-brain GP4
  GP6   rotary encoder A
  GP7   rotary encoder B
  GP8   rotary encoder push switch
  GP9   Back button
  GP10  local button 1
  GP11  local button 2
  GP12  local button 3
  GP13  local button 4
  GP16  optional status RGB; this is the onboard WS2812 on RP2350-Zero
  GP26  ADC0 pressure-sensor input
  GP28  I2C0 SDA for SSD1306 OLED
  GP29  I2C0 SCL for SSD1306 OLED

Connect each button between its GPIO and ground and use a pull-up. External
pull-ups are preferable on a finished PCB; firmware may also enable the internal
pull-ups.

The OLED and distance sensor use separate hardware I2C controllers. GP28 and
GP29 are exposed on the RP2350-Zero module, so the OLED does not require its
underside-only GP20 and GP21 pads.


Secondary brain
---------------

The secondary brain owns the MAX3421E USB host, native USB MIDI device,
external DIN/TRS MIDI, USB2514B hub control, and output fan-out.

  GP0   MAX3421E MISO / SPI0 RX
  GP1   MAX3421E CS
  GP2   MAX3421E SCK / SPI0 SCK
  GP3   MAX3421E MOSI / SPI0 TX
  GP4   UART1 TX to main-brain GP5
  GP5   UART1 RX from main-brain GP4
  GP6   MAX3421E hardware reset, active low
  GP7   USB2514B RESET_N, active low
  GP8   MAX3421E interrupt
  GP12  UART0 TX to external DIN/TRS MIDI output circuitry
  GP13  UART0 RX from external DIN/TRS MIDI input circuitry

The RP2354A dedicated USB DP and DM pins provide native USB MIDI. On an
RP2350-Zero clone, native USB is already routed to the module's USB-C connector.


MAX3421E electrical notes
-------------------------

  MISO connects to GP0.
  CS connects to GP1.
  SCK connects to GP2.
  MOSI connects to GP3.
  RST connects to GP6 and needs a pull-up to 3.3 V so it does not float.
  INT connects to GP8.

The firmware must explicitly select the SPI0 pins:

  SPI.setRX(0)
  SPI.setSCK(2)
  SPI.setTX(3)

The vendored USB Host Shield 2.0 library must declare CS GP1 and interrupt GP8:

  MAX3421e<P1, P8>

Keep the vendored library and patches/USB_Host_Shield_2.0_RP2040_pins.patch in
sync when the new hardware firmware is created. A build still configured for
MAX3421e<P1, P26> will not receive MAX3421E interrupts on this PCB.


Inter-brain UART
----------------

  Main GP4 TX connects to secondary GP5 RX.
  Main GP5 RX connects to secondary GP4 TX.
  Both boards must share ground.
  Start at 1 Mbps and validate 2 Mbps after the queues and PCB are stable.


RP2350-Zero clone notes
-----------------------

GP16 is connected to the module's onboard WS2812 and is reserved for status use.
This plan avoids GP17 through GP25 because those signals are available only on
the module's small solder pads. The required project connections use the easier
outer pins GP0 through GP13 and GP26 through GP29.

An RP2350-Zero clone uses its RP2350A and external 4 MB flash. The custom PCB
uses RP2354A internal flash, so the firmware board target and flash layout must
match the hardware being built even though the functional GPIO allocation is
the same.
